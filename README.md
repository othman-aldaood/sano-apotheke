# Sano Apotheke

Eine moderne, mehrsprachige Website für eine Online-Apotheke mit benutzerfreundlicher Oberfläche und Mehrsprachunterstützung.

## 📋 Beschreibung

Sano Apotheke ist ein responsives Webprojekt, das eine Online-Apotheke präsentiert. Das Projekt bietet eine intuitive Benutzeroberfläche mit Unterstützung für mehrere Sprachen und moderne Designprinzipien.

## 🚀 Features

- **Mehrsprachige Unterstützung**: Unterstützung für verschiedene Sprachen
- **Responsive Design**: Optimiert für Desktop, Tablet und mobile Geräte
- **Moderne Benutzeroberfläche**: Sauberes und professionelles Design
- **Interaktive Elemente**: JavaScript-basierte Funktionalität
- **Impressum**: Rechtliche Informationen

## 📁 Projektstruktur

```
sano-apotheke/
├── index.html          # Hauptseite der Website
├── impressum.html      # Impressum/Rechtliche Informationen
├── style.css           # Stylesheet für das Design
├── script.js           # JavaScript für Interaktivität
├── translations.json   # Mehrsprachige Übersetzungen
├── img/                # Bilderordner
└── .gitattributes      # Git-Konfiguration
```

## 🛠️ Technologie-Stack

- **HTML** (58.9%) - Strukturierung der Webseite
- **CSS** (29.3%) - Styling und Layout
- **JavaScript** (11.8%) - Interaktive Funktionalität

## 📦 Installation

1. Repository klonen:
   ```bash
   git clone https://github.com/othman-aldaood/sano-apotheke.git
   ```

2. In das Verzeichnis navigieren:
   ```bash
   cd sano-apotheke
   ```

3. Die `index.html` Datei in einem Webbrowser öffnen oder einen lokalen Server starten:
   ```bash
   # Mit Python 3
   python -m http.server 8000
   
   # Oder mit Node.js (falls http-server installiert)
   npx http-server
   ```

## 🌐 Sprachunterstützung

Das Projekt nutzt `translations.json` für die Mehrsprachunterstützung. Neue Sprachen können durch Hinzufügen von Einträgen in dieser Datei unterstützt werden.

## 📄 Dateiübersicht

### index.html
Die Hauptseite der Website mit allen wichtigen Elementen und Inhalten.

### impressum.html
Eine dedizierte Seite für rechtliche Informationen und das Impressum.

### style.css
Umfangreiches Stylesheet mit:
- Responsive Design
- Layout und Positionierung
- Farb- und Typografierichtlinien
- Animationen und Übergänge

### script.js
JavaScript-Code für:
- Benutzerinteraktionen
- Sprachweiterleitung
- DOM-Manipulation
- Dynamisches Verhalten

### translations.json
JSON-Datei mit Übersetzungen für verschiedene Sprachen und Textelemente.

## 💡 Nutzung

1. Öffnen Sie die Website in einem Webbrowser
2. Navigieren Sie durch die verschiedenen Seiten
3. Wählen Sie Ihre bevorzugte Sprache aus der Sprachauswahl
4. Erkunden Sie die Funktionalität der Website

## 📱 Responsive Design

Die Website ist für alle Bildschirmgrößen optimiert:
- Desktop (1920px und größer)
- Tablet (768px - 1024px)
- Mobile (320px - 767px)

## 🔧 Entwicklung

Um das Projekt zu erweitern oder zu modifizieren:

1. Bearbeiten Sie die HTML-Dateien für strukturelle Änderungen
2. Aktualisieren Sie `style.css` für Design-Änderungen
3. Modifizieren Sie `script.js` für neue Funktionalität
4. Erweitern Sie `translations.json` für neue Sprachen
